# HTMLColorPicker

HTMLColorPicker is a lightweight and web-based HTML Color picker (hex/RGB) created by Justin Verstijnen. This tool can be used to pick different colors based on a color gradient which we often need for different scenario's like CSS, HTML but also Microsoft Entra ID tenant customization.
## Main features

The main features of this tool are:

- Pick your favorite color and get the corresponding HTML hex/RGB code
- History of the last used colors

## Hosting

This tool is currently hosted on GitHub Pages. Configuration changes are pushed and built using the default deployment method.

## Technical Architecture

- **Languages** : HTML, CSS, Javascript
- **Platform** : GitHub Pages
- **Runtime model** : Serverless
- **Dependencies** : None
