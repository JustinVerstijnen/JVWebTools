# JVWebTools

JVWebTools contains my [tools.justinverstijnen.nl](https://tools.justinverstijnen.nl/) webpage with all the underlying tools on a single GitHub repository for hosting. All the tools are mirrored from their own repositories to host them on a single instance. To learn more about this construction, [check out this blog](https://justinverstijnen.nl/upload-multiple-github-repositories-into-a-single-azure-static-web-app/) where I give a step-by-step guide.

## Main features

The main features of this tool are:

- Hosting all my tools
- Iframes for API-driven tools for uniform URLs
- Tools showcase page with search function
- Modern-style and responsive webpage

## Hosting

This tool is currently hosted on GitHub Pages. Configuration changes are pushed and built using the default deployment method.

## Technical Architecture

- **Languages** : HTML, CSS, Javascript
- **Platform** : GitHub Pages
- **Runtime model** : Serverless
- **Dependencies** : None
